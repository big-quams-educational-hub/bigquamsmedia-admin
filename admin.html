🧮 Post-UTME Calculator

ℹ️ How this works

Each school has its aggregate formula. Students select their school, enter JAMB + O'level scores, and calculate their aggregate. They can then download results as a PDF with the Big Quams Media® watermark — labelled as a record document, not an official result.

🏫 Schools & Formulas
➕ Add School
JAMB score is weighted at 50%, O'Level grades weighted at 50%. Result is out of 100.
Describe how the aggregate is calculated clearly
📤 Bulk Upload Schools (JSON)

📋 JSON Format

Upload a .json file containing an array of school objects. Each object must have: name, abbr, formula (50-50 / 40-60 / 60-40 / jamb-only / custom), and optionally type, location, cutoff, notes, fees, link.

[
  {
    "name": "University of Lagos",
    "abbr": "UNILAG",
    "type": "federal",
    "location": "Lagos State",
    "formula": "50-50",
    "cutoff": 200,
    "notes": "CBT — 50 questions, 30 mins.",
    "fees": "₦80,000–₦180,000/yr",
    "link": "https://unilag.edu.ng"
  }
]
📂Tap to select JSON file

📅 Daily Hub Management

ℹ️ How Daily Hub Works

The Daily Hub page (daily.html) automatically rotates 30 built-in challenge questions by day of year — everyone gets the same question daily. The DYK facts pull from your existing dyk.json file. To add more content:

  • Add new Did You Know facts via the DYK section in this admin panel
  • The challenges auto-rotate — 30 questions cover a full month cycle
  • Students earn 5 coins per correct answer, tracked in their CBT profile
  • Daily streaks are saved to Firestore for signed-in students
